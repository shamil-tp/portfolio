About Shamil TP

Backend-focused full stack developer from Kerala, India, studying for an MCA at St. Joseph's College (Autonomous), Devagiri.

Background

I'm Shamil TP (my name appears as Shamil T P on some certificates, and my handle is shamil-tp on GitHub). I'm a developer motivated by a sincere interest in how the internet works underneath. I can build responsive frontends, but my area is the backend, where data efficiency, server architecture and logic come together.

I like low-level details because memory and performance work has a noticeable effect, and I enjoy making systems faster and more dependable. Since November 2023 I've worked as a freelance full stack developer for independent clients, and from December 2024 to March 2025 I was a full stack development intern at Fugipie Technologies.

My home server

I maintain a personal home server running Ubuntu Server, with Nginx in front, and I deploy most of my backends to it.

Releases are automated with GitHub Actions. Rewind, my self-hosted music server, is the clearest example: every push runs formatting, vetting and race-detector tests; deploys test, build, smoke-test and ship over SSH; and a version tag builds and publishes a release (see its releases).

IoT experiments

Away from the web, I'm interested in IoT. I write MicroPython for the ESP32 and the Raspberry Pi Pico 2 W; the experiments live in github.com/shamil-tp/micropython.
